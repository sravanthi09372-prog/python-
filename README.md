# ATM Application

## 📌 Project Description
This is a simple ATM Application developed using Python.
It allows users to perform basic banking operations through an ATM-like interface.

## 🚀 Features
- Check account balance
- Deposit money
- Withdraw money
- Exit the application

## 🛠️ Technologies Used
- Python

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the `ATM Application.py` file.
4. Follow the instructions displayed by the application.

## 🎯 Purpose
This project was created to practice Python programming concepts and build a simple real-world application.
